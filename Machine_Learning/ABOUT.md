# About AI_LEARNINGS

**AI_LEARNINGS** is a hands-on machine learning repository designed for learners who want practical exposure to common ML algorithms, preprocessing techniques, model evaluation methods, and notebook-driven workflows.

The repository is organized into focused topics and includes both Jupyter notebooks and example datasets. Each module demonstrates the end-to-end steps for loading data, preparing features, training models, evaluating results, and applying key machine learning concepts.

## Core Topics Covered

- Regression: single-variable and multivariate linear regression, one-hot encoding, model persistence, and training/testing split.
- Classification: Logistic Regression, K-Nearest Neighbors, Naive Bayes, Decision Trees, Random Forest, and Support Vector Machines.
- Clustering: K-Means clustering for unsupervised segmentation.
- Model validation: training/testing splits and K-fold cross validation.
- Outlier detection: IQR, percentile-based filtering, and Z-score / standard deviation methods.
- Dimensionality reduction: Principal Component Analysis with real-world dataset examples.
- Feature engineering: tokenization, encoding, and practical dataset preparation.

## Repository Modules

- `Decision Tree` — Decision tree model with salary dataset analysis.
- `Embeddings` — Embeddings exploration for feature representation.
- `Hyperparameter Tuning` — Methods to tune model parameters and improve performance.
- `K-fold Cross Validation` — Techniques for cross-validation and robust evaluation.
- `K-Means Clustering` — Unsupervised clustering example.
- `KNN Classifier` — K-Nearest Neighbors classification for Iris and digit datasets.
- `Linear Regression` — Comprehensive regression examples across multiple subfolders:
  - `singlevariate` — Basic linear regression and prediction examples.
  - `multivariate` — Multi-feature regression, hiring, and housing price data.
  - `one-hot-encoding` — Encoding categorical features for regression.
  - `save_model_file` — Model serialization using `joblib` and `pickle`.
  - `training-testing` — Training/test split best practices.
- `Logistic Regression` — Binary classification examples using insurance data.
- `Naive Bayes` — Naive Bayes classification examples and reference notes.
- `Outlier_IQR` — Detecting outliers with the interquartile range.
- `Outlier_Percentile` — Detecting outliers via percentile-based filtering.
- `Outlier_zscore_std_deviation` — Detecting outliers using Z-score methods.
- `Principal Component Analysis` — PCA for dimensionality reduction on health datasets.
- `Random Forest` — Random forest example notebook.
- `Support Vector Method` — SVM classification and evaluation.
- `Tokenization` — Text preprocessing and tokenization experiments.

## Learning Approach

The repository emphasizes interactive learning through Jupyter notebooks. Each notebook is intended to be executed step-by-step, allowing learners to:

- explore datasets,
- understand preprocessing workflows,
- train and evaluate models,
- visualize results,
- and interpret model behavior.

## Recommended Setup

To run the notebooks, install a Python environment and common ML libraries like `numpy`, `pandas`, `scikit-learn`, `matplotlib`, and `seaborn`.

This repository is ideal for beginners and intermediate learners looking to build practical machine learning skills with well-structured examples.
